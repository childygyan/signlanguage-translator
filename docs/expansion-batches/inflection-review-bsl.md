# BSL inflection-candidate review

Reviewed 187 candidates; **25 rejected**, **162 approved**.
Rule applied: reject when the inflected word's primary (or strongly competing) meaning is conceptually different from the base entry's meaning, or when the inflected form is not valid English. When in doubt, rejected (the variant stays fingerspelled).
